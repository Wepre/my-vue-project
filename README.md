# 健身房器械管理系统 (Gym Equipment Management System)

一个基于Vue 3的现代化健身房器械展示与管理系统，提供直观的器械信息展示和便捷的后台管理功能。

## 🌟 项目特色

- **现代化技术栈**: 采用Vue 3 + Composition API开发
- **美观的UI界面**: 基于Element Plus组件库，提供专业的视觉体验
- **响应式设计**: 完美适配桌面端和移动端设备
- **本地数据管理**: 使用Pinia状态管理和localStorage实现数据持久化
- **图片上传预览**: 支持本地图片上传和实时预览功能
- **权限管理**: 简单的管理员认证系统

## 🚀 技术栈

### 核心技术
- **Vue 3** - 渐进式JavaScript框架
- **Vue Router 4** - 官方路由管理器
- **Pinia** - 直观的状态管理库
- **Element Plus** - 基于Vue 3的组件库

### 开发工具
- **Vue CLI** - 标准化开发工具链
- **ESLint** - 代码质量检查
- **Babel** - JavaScript编译器

## 📋 功能特性

### 用户端功能
- **器械浏览** - 卡片式展示所有健身器械
- **详情查看** - 查看器械详细信息和使用说明
- **健身房介绍** - 了解健身房基本信息和设施

### 管理端功能
- **管理员登录** - 简单的身份验证系统
- **器械管理** - 添加、编辑、删除器械信息
- **图片管理** - 支持本地图片上传和预览
- **实时预览** - 编辑时实时查看图片效果

## 🎯 快速开始

### 环境要求
- Node.js >= 14.0.0
- npm >= 6.0.0

### 安装依赖
```bash
npm install
```

### 开发环境运行
```bash
npm run serve
```

### 生产环境构建
```bash
npm run build
```

### 代码质量检查
```bash
npm run lint
```

## 📁 项目结构

```
src/
├── assets/          # 静态资源
├── components/      # 可复用组件
├── router/          # 路由配置
├── stores/          # 状态管理
└── views/           # 页面组件
    ├── Home.vue     # 首页 - 器械列表
    ├── Detail.vue   # 器械详情
    ├── Login.vue    # 管理员登录
    ├── Manage.vue   # 器械管理
    ├── Add.vue      # 添加器械
    └── About.vue    # 健身房介绍
```
